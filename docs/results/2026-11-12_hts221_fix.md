# HTS221 conversion fix (2026-11-12)

Change: temperature and humidity are no longer taken from ST's `BSP_TSENSOR_ReadTemp()` /
`BSP_HSENSOR_ReadHumidity()`, which truncate the HTS221's calibration points
(`2026-11-12_sensor_check.md`, section 4). `Core/Src/hts221_calib.c` reads the calibration once at
start-up and converts each raw sample with the datasheet formula (T0/T1 = x8 / 8, H0/H1 = x2 / 2).
ST's driver files are unmodified; the BSP still initialises both sensors and still supplies pressure.

## 1. Host test against the documented values

`hts221_calib.c` compiled with the host's gcc (with a stub `SENSOR_IO_ReadMultiple()` that returns
the 16 calibration bytes and the raw sample of `2026-11-12_sensor_check.md`):

```
T0=20.375 T1=34.000 H0=31.0 H1=69.5 H_OUT=-16528 T_OUT=-291
T = 15.261 C (expect 15.261), RH = 81.484 % (expect 81.484)
```

Identical to the Python recomputation in `2026-11-12_sensor_check.md`, section 3.

- The calibration bytes are the same as in the dump of `2026-11-12_sensor_check.md`.
- Python, from those bytes and this run's raw sample (H_OUT = -16288, T_OUT = -274): datasheet
  15.562 °C, 80.752 %; ST's formula 15.055 °C, 80.106 %. Identical to the board's values. The
  "datasheet formula (samples)" line is computed by the same functions as the samples.
- Sample #1 (15.56 °C, 80.75 %) is the datasheet value; before the fix the samples showed ST's value.
  On this board the samples are now **+0.51 °C and +0.65 %RH** higher than before (at about 15 °C).
- 15 valid samples in 75 s; stack report as in `2026-11-12_stack_baseline.md` (Sensors 189,
  Console 235 words used at most: unchanged, the peaks are in the start-up check and in `printf()`);
  both heap counters 0.
- **The sample period is now 5.001 s** instead of 5.005 s: a reading is one 4-byte HTS221 transfer plus
  the LPS22HB's three, instead of ST's driver's eight HTS221 transfers, most of which re-read the
  calibration on every call (see exercise 9.1).
- The first console line of the capture file, `%  p = 976.40 hPa`, is the end of a line from the
  firmware that ran before flashing: the script starts listening before it resets the board.
