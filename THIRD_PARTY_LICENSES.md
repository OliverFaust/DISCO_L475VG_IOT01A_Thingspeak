## Files generated by STM32CubeMX

STM32CubeMX generated these files of the project; they carry ST's copyright notice and say that they
are "licensed under terms that can be found in the LICENSE file in the root directory of this software
component", i.e. this project's `LICENSE`. Code between `USER CODE BEGIN` and `USER CODE END` in them is
this project's:

`Core/Src/main.c`, `freertos.c`, `stm32l4xx_it.c`, `stm32l4xx_hal_msp.c`, `stm32l4xx_hal_timebase_tim.c`,
`system_stm32l4xx.c`, `syscalls.c`, `sysmem.c`; `Core/Inc/main.h`, `stm32l4xx_it.h`,
`stm32l4xx_hal_conf.h`; `Core/Startup/startup_stm32l475vgtx.s`; `STM32L475VGTX_FLASH.ld`,
`STM32L475VGTX_RAM.ld`.

`Core/Inc/FreeRTOSConfig.h` is generated from FreeRTOS's template and carries its MIT notice (Amazon
and ST); the trace hooks in its USER CODE section are this project's.

**Checked 2026-11-14:** every file above still carries ST's notice (copyright line, licence sentence,
"AS-IS"; `system_stm32l4xx.c` also its closing `(C) COPYRIGHT STMicroelectronics` line, identical to
FW_L4 V1.18.2's template), unchanged since the first commit; no commit in the history removed a
copyright or licence line from them. The 140 files under `Drivers/STM32L4xx_HAL_Driver`,
`Drivers/CMSIS`, `Drivers/BSP` and `Middlewares/Third_Party/FreeRTOS` are byte-identical to STM32Cube
FW_L4 V1.18.2 (`Drivers/BSP/README.md`, this project's note on their origin, excepted).
